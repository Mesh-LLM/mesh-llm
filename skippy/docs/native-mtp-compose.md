# Native immutable MTP composition

The native default flow is `just hf-skippy-mtp-compose-default request.json /absolute/fresh/evidence`. The closed request selects immutable checkpoint/tokenizer repository revisions and complete file SHA256 pins, an explicitly accepted byte-bound Nemotron tokenizer profile, a pinned checkpoint-staging helper, pinned native bootstrap tools/source identities, complete ordered target GGUF parts, and pinned repository/publisher helpers.

The checkpoint and tokenizer repositories correspond to the historical defaults `nvidia/Nemotron-3-Super-120B-A12B-BF16-MTPv2` and `nvidia/NVIDIA-Nemotron-3-Super-120B-A12B-BF16`. Revisions and content pins must be supplied. Target parts come from the original target `UD-Q4_K_XL` directory; native admission requires explicit complete ordered pins instead of inferring acceptance from a glob. The original target/composite basenames, block 88, and meshllm composite repository remain JSON defaults.

`dry_run: true` writes a declared phase plan and starts no children. Real execution requires `confirm_publication: true`, Linux, an explicit overall budget and publication reserve, and a private credential file. No helper loads ambient HF credentials. The operator must approve any actual source checkout/build, model acquisition, or public publication separately; this source migration does not authorize those operations.

Execution downloads pinned checkpoint bytes into owned local files, fills missing tokenizer assets while retaining checkpoint precedence, and verifies the explicit tokenizer profile. It reuses the existing observed native bootstrap, native BF16 MTP conversion/verification, and first-shard metadata/last-shard tensor composition with untouched middle pins. Public repository provisioning supplies an observed parent; all ordered shards and sidecars plus an honest source card publish in one parent-bound commit, followed by the existing immutable remote byte verification. Publication success cannot replace native attachment success. A final cancellation/deadline/interrupt gate precedes the durable `COMPOSED_PUBLISHED` report. Failed reports retain completed phases and uncertain publication progress.

The tiny fixtures use inert bootstrap/product/HF helpers. They do not establish actual Nemotron tokenizer compatibility, native GGUF loading, a usable image, cost, or real HF publication. Actual model acceptance and immutable remote bytes remain operator validation gates. The historical Python caller remains until the native owning tests and final migration validation pass; recorded historical Python commands remain provenance.
