# Native default MTP composition Jobs

Use the existing model-package-generic-jobs prepare/submit/collect facade with worker_input.workflow set to default-mtp-composition. Its operator is the full compose-default request, with credential_file:null, explicit immutable checkpoint/tokenizer revisions and SHA rosters, accepted tokenizer profile pin, ordered target parts, source/helper pins, bootstrap and image declarations, and confirmed publication or dry_run. timeout_secs, operator.overall_seconds, bootstrap.timeout_seconds and CpuJobPlan.timeout_seconds match, up to259200 seconds. The supplied image contains the pinned runner and all existing helpers; this adapter builds no image and guesses no tokenizer profile.

Readonly immutable mounts supply target GGUF parts. Checkpoint/tokenizer acquisition remains owned by the pinned stitching helper under the same remaining budget. The worker reserves the receipt-export allowance first, then the existing composition publication allowance. Bootstrap, native convert/verify/attach, repo provision and complete ordered model publication all reuse their owning phases. It exports native-job.json through the existing private regular JSON helper.

Prepare is read-only. Explicitly authorized submit uses --confirm-submission and a private credential file. Archive the original request and submitted.json; collect uses both with the same facade. Successful full composition is COMPOSED_PUBLISHED inside COMPOSITION_COMPLETED evidence and COMPOSITION_ADMITTED after terminal remote observation and immutable retrieval. Plan-only COMPOSED and CERTIFIED are rejected. Dry-run is a declared nonexecution outcome, not model/publication acceptance. Failed/cancelled jobs retain observed phases and mutation uncertainty. A local signal stops observation/owned children; no automatic remote cancel is implied.

The inline request limit is 64 KiB. The mounted request transport supports the full canonical worker document up to 8 MiB, with readonly immutable mount/hash/byte custody. Use the offline plan and export-request steps in HF_GENERIC_CONVERSION_JOBS.md for helper preparation, resources and exact request bytes. Real Linux image, native Nemotron/profile/target and public HF execution remain unqualified. Jobs spending and publication require explicit operator authority. Local preparation and finite fixtures do not qualify a real cloud image or model.
