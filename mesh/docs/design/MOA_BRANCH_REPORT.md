# Mixture-of-Agents extraction

Mixture-of-Agents is being moved to the optional `Mesh-LLM/moa-plugin`
repository and is not installed by default. Core `mesh`/`auto` requests select
one compatible model; an installed plugin can override non-streaming text
chat. The previous implementation and evaluation material are preserved in
mesh-llm history at `3c90d58d9`. MoA quality is not established.
