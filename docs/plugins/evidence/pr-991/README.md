# PR #991 hosted plugin web UI evidence

Generated by `crates/mesh-llm-ui/e2e/plugins/web-ui-exemplar.live.spec.ts` against the production frontend embedded in `target/debug/mesh-llm`. The test installs and runs the packaged exemplar from an isolated plugin store; it does not use Vite, API interception, or stubbed plugin responses.

- `01-plugin-page-ready.png` — dark-mode plugin page reached through the direct **Exemplar Notes** navigation item, with the interactive sample-note action and the configured 30-day retention window.
- `02-plugin-settings-persisted.png` — the **Plugin settings** banner is the topmost plugin-tab content, above installed-plugin metadata, after the schema setting is persisted as 365 days.
- `03-plugin-schema-setting.png` — the exemplar's manifest schema renders through the standard host controls, including the **Retention days** range input at 365 days.
- `04-plugin-ui-disabled-capability-alive.png` — disabling only the web projection removes its navigation and assets while the exemplar's non-UI capability remains available.
- `live-validation.json` — backend/browser assertions, observed production API traffic, persisted value, and empty console/page-error diagnostics.

The run also verifies invalid values return HTTP 422, the setting refreshes the plugin page immediately after a normal **Save config**, assets use `Cache-Control: no-cache`, and the frontend is served from `http://127.0.0.1:13131` with no Vite client.
